# First Steps For Exploiting Windows Machines

<h3>Find open ports</h3>

nmap -sC -sV -Pn -p- [HOST]

<h3>Enumerate with crackmapexec</h3>

crackmapexec [SERVICE] [HOST] -u [USERNAME] -p [PASSWORD]
